# 🚀 Juan Alonso's Engineering Portfolio

> A high-performance, single-page React application built to showcase my computer engineering, embedded systems, and full-stack projects. 

🔗 **[View Live Portfolio](https://juanalonso278.github.io/portfolio/)**

*(Note: You can add an image link to a screenshot of your website here later!)*

## ✨ Features

- **Instant Project Filtering:** Clickable tags on the home page instantly filter projects without reloading or layout shifts.
- **Embedded PDF Reporting:** Built-in PDF viewer for reading technical project reports directly on the site.
- **Modern Glassmorphic UI:** A clean, dark-mode aesthetic with translucent elements, glowing accents, and smooth transitions built entirely with custom CSS.
- **Easy Content Management:** New projects can be added simply by dropping a new data file into the `src/projects/` folder—no need to redesign the page layout.

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, React Router
- **Styling:** Custom Vanilla CSS (Zero-dependency, using CSS Variables)
- **Build Tool:** Vite (for lightning-fast hot module replacement and optimized production builds)
- **Deployment:** GitHub Pages & GitHub Actions

## 🚀 Running Locally

If you'd like to run this project on your local machine:

1. **Clone the repository**
   \`\`\`bash
   git clone https://github.com/juanalonso278/portfolio.git
   cd portfolio
   \`\`\`

2. **Install dependencies**
   \`\`\`bash
   npm install
   \`\`\`

3. **Start the development server**
   \`\`\`bash
   npm run dev
   \`\`\`

4. **Build for production**
   \`\`\`bash
   npm run build
   \`\`\`
